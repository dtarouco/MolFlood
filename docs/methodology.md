# MolFlood Methodology

MolFlood predicts `docking_score` values generated by documented docking protocols.

The current molecular representation combines Morgan fingerprints with RDKit physicochemical descriptors.

The held-out test set is not used for algorithm selection or Optuna. Structural split modes use group-aware validation, including GroupKFold when applicable.

Validation includes regression metrics, ranking behavior, bootstrap analysis, Y-scrambling, and Morgan/Tanimoto applicability-domain analysis.

External ML predictions can be compared with independently generated reference/redocking scores when available.

Prediction output alone is not treated as validation evidence.
