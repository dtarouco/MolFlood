# MolFlood Tutorial Dataset

A developer-provided tutorial dataset is planned for the public release.

The tutorial should allow a new user to install the environment, run the notebook from a clean kernel, reproduce the reference workflow, inspect generated artifacts, test external prediction, and understand applicability-domain output.

Expected minimum schema:

```csv
smiles,docking_score
CCO,-5.8
c1ccccc1,-6.4
```

The tutorial dataset should only be added when its provenance and redistribution rights are confirmed. Its data license may differ from the MIT License used for MolFlood source code.
